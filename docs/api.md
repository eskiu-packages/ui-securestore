## `<securestore>`

`<securestore>`: small secrets kept by the platform's secure storage, for apps on
eskiu-packages/ui: a session token, a refresh token, a key. The Keychain on iOS and macOS,
values encrypted with an AES-GCM key held by the Android Keystore on Android, the Secret
Service (GNOME Keyring, KWallet) through libsecret on Linux, and DPAPI on Windows. The web,
and the desktop's webview builds, have no such store: there secure_is_secure is false and
secure_set refuses (returns false) and secure_get returns null, unless the app opted in with
secure_allow_insecure(true), which keeps values in localStorage, in the clear. On Linux
without libsecret or a running Secret Service, set and get fail and secure_is_secure is
false; nothing is written in the clear there, opted in or not.

```eskiu
secure_set("session", token);
string saved = secure_get("session");    // null when there is none; free it
defer free(saved);
```

### secure_allow_insecure

```eskiu
void secure_allow_insecure(bool allow)
```

Lets the web, and the desktop's webview builds, keep values in localStorage, in the clear,
readable by any script in the page and from the browser's profile. Off by default: without
it secure_set refuses and secure_get returns null where secure_is_secure is false. Call it
only for values you would not mind being read there. It changes nothing where the platform
has a secure store, and Linux without a Secret Service still keeps nothing.

### secure_get

```eskiu
string secure_get(string key)
```

The value kept under `key`, a copy the caller frees, or null when there is none, or when the
platform has no secure store and the app did not call secure_allow_insecure(true).

### secure_set

```eskiu
bool secure_set(string key, string value)
```

Keeps `value` under `key`, replacing what was there; false when the platform refused, or
when it has no secure store (the web, the desktop's webview builds, Linux without a Secret
Service) and the app did not call secure_allow_insecure(true).

### secure_remove

```eskiu
bool secure_remove(string key)
```

Forgets `key`; true when nothing is kept under it afterwards. It works without a secure
store too, so an app can remove what an earlier version kept in the clear.

### secure_is_secure

```eskiu
bool secure_is_secure()
```

Whether values are kept encrypted by the platform: true on iOS, Android, macOS, Windows,
and Linux with a Secret Service; false on the web and in webview builds and on Linux
without one. Where it is false, secure_set refuses and secure_get returns null, unless the
app called secure_allow_insecure(true) (then the web keeps values in localStorage, in the
clear).
